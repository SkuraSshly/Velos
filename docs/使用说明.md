# Velos 使用说明

Velos 是一个轻量的 macOS 截图与录屏工具，常驻菜单栏，用快捷键唤起。

- 默认不联网、不收集任何数据、默认不检查更新
- 下载约 4 MB，空闲时内存约 14–50 MB、CPU 0%
- 空闲时不运行任何屏幕采集；Velos 自己的界面不会出现在截图和录屏里

## 系统要求

macOS 15 或更新，Apple 芯片的 Mac。

## 安装

1. 打开 `Velos-2.8.dmg`，把 **Velos** 拖到旁边的「应用程序」文件夹。
2. 在「应用程序」里打开 Velos。第一次运行会打开 设置 › 通用，在最下面的「权限」里点「授权」：
   - **屏幕录制**（必需）：截图和录屏都需要。在系统设置里打开后，点「重新启动」。
   - **麦克风**（可选）：只有录屏时要录自己的声音才需要。
   已授权的那一行是「取消授权」，点它跳到系统设置里关掉。
3. 想开机自动运行：菜单栏图标 › 设置 › 通用 › 打开「登录时打开」。想在程序坞里也有图标：设置 › 通用 › 打开「程序坞图标」（点图标打开设置，右键可以截图、录屏、截屏翻译）。

> **移动过 Velos.app 的位置？** 登录项记录的是 App 所在的位置。把 Velos 换到别的文件夹后，
> 请在设置里把「登录时打开」关掉再打开一次，让它指向新位置。

> **拷到其他 Mac 上用？** 这个版本使用本机签名（ad-hoc），没有经过 Apple 公证。
> 在别的 Mac 上第一次打开时 macOS 会拦下，需要到 系统设置 › 隐私与安全性 里点「仍要打开」。
> 要让别人直接打开，需要 Apple 开发者账号（每年 99 美元）签名并公证。

## 功能

**截图**：冻结画面后框选；自动识别窗口；放大镜；拖动控制点调整；标注工具（矩形、椭圆、箭头、直线、画笔、荧光笔、文字、序号、马赛克、模糊，按住 ⇧ 画正方形、正圆，或沿 45° 整数倍方向的直线和箭头；颜色、不透明度、粗细 / 字号 / 强度都可以在属性栏的拉条上精确调整，每种工具各自记住上次的设置）；钉在屏幕上；圆角截图：选好区域后，尺寸标签右边有「圆角」拉条（0–40 点，可以在上面滚动微调），选区直接显示圆角的样子，截出来的图圆角外透明（PNG、HEIC 保留透明，JPEG 填白色），上次的大小会记住；以 Retina 原生像素输出并写入色彩配置文件。

**窗口截图保留圆角**：单击（或悬停）选中一整个窗口截图时，只截窗口本身，四个圆角外透明（和系统按住 ⌥ 截窗口一样）。框选的区域、露出屏幕外的窗口、菜单栏和程序坞照样是直角。在 设置 › 截图 里可以关掉圆角，或再加上窗口阴影（默认不加）。

**晾衣绳**：最近的截图和录屏挂在屏幕顶上的一根绳子上，平时藏在菜单栏后面。按住 ⌥（设置里可以换成 ⌘ / ⌃ / ⇧）把鼠标移到屏幕最上面它就滑下来（全屏 App 里也行；不按这个键碰到顶部不会掉下来），鼠标离开 1 秒就收回去（刚拖走一张、用完右键菜单或快速查看时，要等鼠标回到绳上再离开才收，方便接着拖下一张）；也可以按 ⌥F 或点菜单「晾衣绳」。截完图，截图会从截下来的位置飞到绳上挂好，绳子放下来给你看 2.5 秒。第一次用时绳子会自己下来一次，告诉你怎么叫它。绳上：鼠标停在一张上，右下角是「复制」，右上角是衣架「钉在绳上」（再点一次取消），左下角「存文件」（存到截图文件夹；存好后左下角换成删除，复制前面多一个「打开文件位置」），左上角 ✕ 取下（也可以按 Delete）；录屏右下角是「GIF」「打开文件位置」「复制」，左下角是删除（删除的是文件本身，进废纸篓还是永久删除按 设置 › 通用 › 删除文件）；在访达里删掉存好的截图或录屏文件，绳子会先下来，再把对应的那张拿掉给你看；右键「在访达中显示」只在存过文件后出现；按空格是系统的快速查看（按住空格看、松开就回去；点按一下一直开着，再点按一下关上，← → 翻看其他几张，顶上能旋转、标记）；拖进微信、PPT、访达等任何地方就是放过去，它会从绳上走掉（没地方接收就飞回来）；⌘ 单击加选、⇧ 单击连选一段后一起拖走（选着的时候绳子不会收起）；右键可以快速查看、打开、共享（隔空投送等）、保存到文件、在访达中显示；取下或拖走后，鼠标在绳上时按 ⌘Z 能放回来（最近 10 步）。同一张图（像素完全一样）从不同地方进来只挂一次，再来一次会挪到最右边。按住访达、浏览器里的图片往屏幕顶上拖，绳子会下来接，松手就挂上；在访达里选中图片或录屏，右键「打开方式 → Velos」，或拖到程序坞里的 Velos 图标上，也能挂上。在 设置 › 晾衣绳（在「截屏翻译」下面）里可以：关掉晾衣绳、选按住哪个键、选照片大小（小 / 中 / 大）、保留几张（一屏 / 25 / 50 / 100 张，一屏放不下的在绳上双指左右滑或用滚轮看）、打开「挂上剪贴板里的图片」（默认关）。调度中心开着时绳子会让开。晾衣绳靠系统抄送的鼠标事件知道鼠标在哪（只听、不拦截），鼠标不动时不占任何资源；只有鼠标停在屏幕最上面等你按键的几秒里、或开了「挂上剪贴板里的图片」时才会定时看一下。截图时「咔嚓」一声、挂上绳「叮」，取下、删除、拖到废纸篓是同一声低沉的「噗」，拖进别的 App 是上扬的「嗖」（拖进访达不响），撤销放回、钉在绳上也「叮」；在访达里删掉文件后绳上那张悄悄拿掉。这些声音和 Tendedero 网站上的一样，是当场合成的，不用任何声音文件。录屏倒计时每秒一声、开始和结束各一声（系统的提示音，不会录进视频）。都可以在 设置 › 通用 › 提示音 里关掉。设计来自开源项目 Tendedero 和 Picline（见 THIRD_PARTY_NOTICES.md）。

**截图之后**：右下角出现缩略图——单击继续编辑（编辑窗口里按住 ⌥ 滚动或双指捏合缩放，滚轮每格 15%，缩放时显示比例，100% 是原像素，最大 400%；放大后滚动查看各处；⌘= 放大、⌘- 缩小、⌘0 回到原来大小），拖进任何 App，点「保存」存为文件，或钉在屏幕上（原始大小、钉在原位，钉上就是选中状态；拖边缘或四个角调整大小）。粘贴过的截图缩略图会自动收起。**只有点「保存」或按 ⌘S 才会写文件**。

**录屏**：区域或全屏；HEVC / H.264 硬件编码；系统声音与麦克风实时混成一条 AAC 音轨（48kHz、256kbps、立体声）；暂停 / 继续（暂停的部分不在视频里）；浮动控制条与红框（都不会被录进去）；3 秒倒计时；鼠标点击高亮（会录进视频）。录制中可以照常按 ⌥A 截图、⌥D 截屏翻译，截图界面、标注、翻译结果、缩略图、钉图都会录进视频（录的就是屏幕上看到的），只有录屏自己的控制条和红框不录。

**长截图**：按 ⌥A 框选要截的区域（例如聊天窗口的消息区、网页正文；再按 ⌥A 切到全屏也可以，整块屏幕就是选区），点工具栏的「长截图」（剪刀图标，在钉图、保存的左边，要在画标注之前）。截图界面关闭后，选区外变暗、选区有杏色边框，鼠标和滚轮照常交给下面的 App：在选区里滚动页面，Velos 边滚边拼接，旁边有实时预览，控制条上显示已拼接的长度。开始时只出一条提示，之后的过程中不再出提示。
- 从开始滚动的那一刻拼起：选好区域后画面还在变（刚从调度中心回来、页面刚加载完）也没关系，长图的开头是你开始滚动前一瞬间的画面
- 自动滚动：点控制条上的「自动滚动」，Velos 替你匀速、慢慢往下滚（每秒约三分之一个选区高，越慢拼得越稳），滚到底自动停；再点一次「停止」。鼠标要放在选区里（移出去会暂停）。自动滚动要给其他 App 发滚动事件，需要「辅助功能」权限，第一次用时会请求；只用手动滚动时不需要
- 实时预览：选区右边显示拼好的长图，跟着你滚到的位置走（往回滚时预览也往回）
- 往回滚不会重复拼接
- 不改动你的滚动：Velos 不拦截、不限速、也不读取滚轮事件，鼠标、触控板、平滑滚动工具都照常工作，拼接只看截到的画面；不需要「辅助功能」权限
- 滚得太快：画面变化时每秒最多截 60 帧，滚轮的滚动动画、停下后的画面都会截到。一下甩得太远、和上一次对上的画面没有重叠时，往回滚一点就能接上；继续往下滚的话，过一小会儿会自动从当前画面接着拼（中间没截到的那一段跳过，不会重复、不会错位）。想要完整不漏，滚慢一点就行
- 准确：滚动时浮出的滚动条不影响拼接；滚动时浮出的滚动条不影响拼接；文字有细微差别也能对上；刚滚到时还没画完的内容（空白、模糊），画好后会自动换上
- 顶部固定的标题栏（包括半透明、磨砂的）、底部固定的输入框只出现一次；左右不滚动的边栏（例如会话列表）只保留第一屏，往下用边栏的背景色延伸，不会一段段重复
- 点开长截图的缩略图：按原像素宽度显示，上下滚动查看；按住 ⌥ 往下滚可以缩小到看全整张
- 最长 20000 像素（Retina 屏上约 10000 点）
- 点「完成」：和普通截图一样复制到剪贴板、显示缩略图（可以继续标注、保存、钉图）；点编辑图标直接打开编辑窗口继续标注；点钉图图标把整张长图钉在屏幕上；点保存图标直接存文件；点 ✕ 或按 Esc 取消
- 编辑窗口里图片浮在暖色底上（带投影），一眼看清边界；标注只能画在图片里；长截图右侧有滚动条

**截屏翻译**：按 ⌥D 框选，松开鼠标后结果窗口立即出现，识别出的原文和译文随后填进来（长文逐段显示）。文字识别完全离线；默认用 Apple 翻译（离线、免费，第一次用某对语言时系统会提示下载语言包）。原文可以直接修改，停顿后自动重新翻译；可以换语言、交换语言、朗读。单个单词或短语会查 macOS 自带的词典（「词典」App 里启用的那些）。点 📌 钉住后窗口置顶、可拖动和调整大小，可以同时钉住多个。
在 设置 › 截屏翻译 里可以：选优先识别的语言、智能排版、识别二维码；设默认目标语言（默认中文译成英文、其他译成简体中文）、翻译完成后自动复制译文、朗读语速、默认钉住；在「在线翻译」一项里选服务商（腾讯、火山、百度、有道、DeepL、微软，或 OpenAI 兼容大模型、Claude），填写自己的 Key（保存在钥匙串里）、打开开关并测试；可以逐个启用多个，下拉菜单里已启用的带 ✓。想免费用可以选腾讯翻译君、火山翻译（每月有免费额度），或在大模型里填智谱的免费模型 glm-4-flash（Base URL `https://open.bigmodel.cn/api/paas/v4`）。默认引擎失败时会自动换到下一个可用的引擎，并在译文下面说明。

**录屏之后**：开着晾衣绳时，录好的视频直接挂到晾衣绳上（不再出现在右下角）：鼠标停在卡片上，右下角是「GIF」（导出 GIF，进度显示在卡片上，GIF 存在视频旁边、也挂到绳上）和「复制」（复制视频文件），按空格预览播放，拖进任何 App，左下角的垃圾桶（或右键）删除视频本身，绳上的卡片也一起拿掉；在 设置 › 通用 › 删除文件 里选「放入废纸篓」（默认，能放回来）还是「永久删除」，删除存好的截图也按这个来。（「取下」只是从绳上拿掉，视频文件不动。）关掉晾衣绳时照旧在右下角显示录屏缩略图——单击预览，拖进任何 App，拷贝文件，导出 GIF，移到废纸篓。以前的录屏可以在 设置 › 录屏 › GIF 里「把录屏转成 GIF」。

## 文件保存在哪

| 内容 | 默认位置 | 何时写入 |
|---|---|---|
| 截图 | `~/Pictures/ScreenShots` | 点缩略图上的「保存」或按 ⌘S 时 |
| 录屏 | `~/Movies/ScreenRecordings` | 录制时自动写入 |
| GIF | 与对应的录屏放在一起 | 点「GIF」导出时 |
| 晾衣绳上的截图 | `~/Library/Application Support/local.velos.Velos/History` | 每次截图完成时（关掉晾衣绳时清空） |

## 隐私

- **默认不联网**：截图、录屏、文字识别、Apple 翻译、查词都在本机完成。只有你在 设置 › 截屏翻译 里启用并填了 Key 的在线翻译引擎，才会把要翻译的文字（不是截图）发给那家服务商；关掉引擎就不再联网。
- **不收集数据**：没有统计、没有崩溃上报、没有账号。
- **默认不检查更新**：设置 › 通用 里点「检查更新」才去 GitHub 问一次最新版本号；也可以打开「自动检查更新」（每天一次）。只问版本号，不发送任何关于你的信息。
- 运行日志写在系统日志里（只有操作和参数，例如「开始录制：2560×1440，60 fps」，不含任何画面或声音内容），由系统自动清理。查看：
  `log show --predicate 'subsystem == "local.velos.Velos"' --last 1h`

## 已知限制

- **macOS 会定期弹出「Velos 正在访问你的屏幕」的确认框**（大约每月一次或系统更新后）。这是 macOS 15 对所有录屏类 App 的系统行为，App 无法关闭。
- **系统快捷键不能设为 Velos 的快捷键**（见上文）。
- 菜单栏菜单、钉图右键菜单是系统原生菜单，无法改成温暖风格。
- GIF 每帧最多 256 色：界面演示效果很好，大面积渐变和照片会有色带。
- 用 AirPods 等蓝牙耳机的麦克风录音时，macOS 会把耳机切到通话模式，系统声音的音质随之下降；用 Mac 自带麦克风不会。

## 从源码构建

需要 Xcode 命令行工具（`xcode-select --install`），不需要 Xcode，也没有任何第三方依赖。

| 命令 | 作用 |
|---|---|
| `./build.sh` | 编译 release 版，生成 `build/Velos.app` |
| `./build.sh debug` | 编译调试版（包含自测代码） |
| `./run.sh` | 编译并重新启动 Velos |
| `./package.sh` | 编译并打包成 `dist/Velos-版本号.dmg` 和 `.zip` |
| `swiftc scripts/make-icon.swift -o /tmp/make-icon && /tmp/make-icon Resources/AppIcon.icns` | 重新生成 App 图标 |

源码在 `Sources/Velos`，按功能分文件夹：`Capture`（调度、冻屏）、`Overlay`（选区界面）、`Screenshot`、`Annotation`（标注）、`Pin`（钉图）、`Thumbnail`（缩略图）、`Recording`（录屏、混音、GIF）、`Hotkeys`、`MenuBar`、`Settings`、`Permissions`、`UI`（温暖风格控件）、`Utilities`。
